Why models hallucinate

Every step so far ranks next-token candidates by learned plausibility — how well a continuation fits the training patterns. Nowhere in the arithmetic is there a step that asks "is this actually true?" So a confident, plausible, false token can outrank the correct one.

⏱ ~4 min 🎚 softmax, computed live math: some

Lessons 10 and 11 turned a final vector into vocab-logits and then, through softmax, into next-token probabilities. That whole pipeline ranks tokens by one thing only: how plausible each continuation is, given the patterns the model saw in training.

So when a false answer is more famous or more frequent than the true one, it can carry the higher logit — and win. That's hallucination, mechanically: not the model "lying," just plausibility beating truth, because truth was never a term in the computation.

Below is a toy distribution for "The capital of Australia is ___". Canberra is the real capital; Sydney is the larger, more-talked-about city — the common wrong guess. Watch which one softmax picks.

Show me the actual numbers

Five candidate logits for "The capital of Australia is ___", run through the same softmax(z) = e^z / Σe^z from every other page. Subtracting the max (3.0) for numerical stability, the denominator is Σ e^(z−3.0) = 1.997:

The false-but-famous Sydney (50.1%) beats the true Canberra (15.1%, rank 3). Canberra is Australia's capital; Sydney is its largest, most-talked-about city, so training made Sydney the stronger association here. The softmax ranks by that association — it has no fact table to consult.

Turning up temperature (lesson 11) doesn't fix this — it only changes how often the wrong-but-confident token is sampled; Sydney is still the argmax. (The logits here are illustrative; the mechanism — plausibility with no truth signal — is the real point.)

MythA hallucination is a bug — the model "knows" the truth and glitched, or the temperature was just set too high.
RealityThere's no truth signal in the computation at all. The model ranks by plausibility; when a false token is more plausible than the true one, it wins. It's the same mechanism that produces a correct answer — just pointed at a case where fame outweighs fact.
Takeaway

Prediction picks the most plausible continuation, never the verified-true one — because nothing in the softmax computes truth. A confident, fluent, false token can outrank the correct answer.

Mechanically, why can a model state a confident falsehood?
Why: nothing in the softmax computes truth — only plausibility — so fame or frequency can beat correctness. Same arithmetic as a right answer; truth was simply never a term in it.
