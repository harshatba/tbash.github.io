How attention actually computes

Click a query token and watch the whole pipeline run on real numbers: dot products become raw scores, softmax turns them into weights that sum to 1, and the Values blend into a brand-new vector. Nothing here is looked up — every number falls out of arithmetic you can trace.

⏱ ~7 min 🎚 the full pipeline, computed math: some

Last page we built three vectors from every token's embedding: a Query (what it's looking for), a Key (what it advertises), and a Value (the content it hands over). Now they get used.

To decide how much token A should listen to token B, take A's Query and B's Key and dot them together: q·k. A bigger dot product means the two vectors point the same way — a better match, a higher raw score. Those raw scores are the logits of the attention softmax. (These are attention-logits — one score per token in the sentence. Later, next-token prediction produces vocab-logits — one score per word in the whole vocabulary. Same softmax, different lists; lesson 10 builds the second.)

Run all the scores through softmax and you get positive fractions that add up to 1 — the attention weights. This is the exact same softmax that turns next-token logits into probabilities — the one you'll dial with temperature on lesson 11. Finally, A's new vector is the weighted blend of every token's Value: a token literally becomes a mix of what it paid attention to.

The e^score column sums to 19.83; each weight is that row's e^score divided by 19.83 (e.g. 7.10 / 19.83 = 0.358 = 35.8%). The seven weights add to 1.00.

Blending the Values (each token's v = Wv·e, dim 3 halved) with those weights gives out ≈ [0.62, 0.24, 0.25, 0.10] — animacy-dominant (from cat) with a state bump (from tired).

The √d note: real transformers divide each score by √(key-dimension) before softmax to keep the numbers from getting too large — with d = 4 that's ÷2. It changes the sharpness of the weights but not which token wins. We skip it here so the arithmetic stays clean.

MythThe attention weights are looked up in a table or hand-set by the designer.
RealityThey're computed every single step — dot products of Queries and Keys, run through softmax. Change one vector and every weight downstream changes. (This widget just proved it: edit the toy data and the arcs re-draw.)
Takeaway

Attention is three ops in a row: Q·K dot products → softmax → weighted blend of Values. The output vector for a token is literally a mixture of the tokens it scored highest.
