The feed-forward step: each token thinks alone

Attention was the step where tokens looked at each other. The FFN is the opposite: each token's vector runs through a little neural network on its own — it's lesson 4's neuron, finally eating a real post-attention vector.

⏱ ~5 min 🎚 the net, computed live math: some

Attention mixed information across tokens: it's vector became a blend of cat, tired, and the rest. The feed-forward network does the opposite job — it transforms each token's vector by itself, with no other token involved.

That little network is just lesson 4's neuron, stacked into layers: a hidden layer of neurons hidden = tanh(W1·v + b1), then an output layer out = W2·hidden + b2. Same multiply-add-squish — now chewing on the real residual vector [1.42, 0.34, 0.45, 0.40] that it carried out of lesson 8.

This is where the model transforms what attention gathered — sharpening some features, trimming noise — one token at a time. And its output is added back too (residual, lesson 8): v + FFN(v).

W1 is 8 rows × 4 (one hidden neuron per row) with biases b1; W2 is 4 rows × 8 (one output neuron per row), biases b2 = 0. Sparse on purpose so each worked sum is short and readable.

Added back (residual, lesson 8): the token's running vector becomes [1.42+0.71, 0.34+0.20, 0.45−0.09, 0.40+0.21] = [2.13, 0.54, 0.36, 0.61]. The FFN pushed animacy up further (more clearly cat-flavored) and trimmed the stray state it had picked up from tired.

Every token in the sentence runs through this same FFN, independently. Attention shared information between tokens; the FFN never lets them talk. Change the input vector above and only that token's numbers move — the network has no memory of the others.

MythAfter attention there's more attention — it's attention all the way down.
RealityHalf of every block is the FFN: each token pushed through the same little neuron network alone. Attention mixes across tokens; the FFN transforms each token by itself.
Takeaway

The FFN is lesson 4's neuron, stacked — tanh(W1·v + b1) then a linear W2·h + b2 — run on one token's vector at a time, then added back onto the residual stream.

How is the FFN different from attention?
Why: attention is the cross-token step (Q·K over all tokens); the FFN runs each token's vector through the lesson-4 neuron independently — every token gets the same network, alone.
