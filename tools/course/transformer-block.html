One block, stacked N times

You've now met every piece. Bundle them in order — attention, add back, FFN, add back, with a layer-norm to keep the numbers tidy — and you have one transformer block. A model is that same block repeated. Drag the layer slider and watch a token's vector drift, layer by layer, toward its contextual meaning.

⏱ ~5 min 🎚 drift, computed live math: light

Every step in the last few lessons was a piece of the same machine. Stack them in order and the shape appears: attention (tokens look at each other) → add back → FFN (each token thinks alone) → add back. That whole unit is one transformer block.

One honest extra line: between sub-steps a layer-norm rescales the vector — roughly recenter to mean 0, rescale to a standard size — so that after many add-backs the values don't blow up or vanish. That's its whole job here: keep the running total numerically tidy.

A real model is this same block repeated N times (dozens to ~100), each copy with its own learned weights. The vector that flows through gets refined block by block. Below, watch it's vector drift from raw embedding toward its contextual, cat-flavored meaning as the layers stack up.

Layer-norm (skipped in the toy arithmetic) would rescale each step's numbers back to a standard range so the running total never blows up or vanishes between blocks — the piece that keeps a 100-layer stack numerically stable.

MythEach layer is a different kind of operation — deeper means fancier, more exotic math.
RealityIt's the same block — attention, FFN, two add-backs, a layer-norm — repeated with different weights. Depth just refines the same running vector over and over; the machinery of layer 1 and layer 90 is identical in shape.
Takeaway

One transformer block bundles the cross-token step (attention) and the per-token step (FFN), each added back onto the residual stream, with a layer-norm to stay tidy. Stack that block N times and you have a model; the vector drifts toward its contextual meaning block by block.

What is one transformer block?
Why: a block bundles the cross-token step (attention) and the per-token step (FFN), each added back onto the residual stream, with a layer-norm to keep the numbers in range. Stacking that same block is what makes a model deep.
